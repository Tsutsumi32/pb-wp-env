# manuscript-sheet

実装中の **仮テキスト** を、クライアント確認用の Excel(原稿シート)へ画面単位で書き出す。

**対象外**: 仮画像の一覧(`image-sheet` スキル)。本番確定文言の転記。`manuscript-injection`(原稿の実装投入)とは逆方向。

## 入出力

| 項目 | 内容 |
|------|------|
| 書式の参照元 | `_docs/sheets/原稿シート_テンプレート.xlsx`(**読み取り専用**。編集・複製はしない。書式は下記「Excel 出力仕様」のとおりコードで再現する) |
| 出力 | `_docs/sheets/{SITE_NAME}_原稿シート.xlsx`(既存なら日時サフィックス等で別名。依頼でパス指定があれば従う) |
| シート | **仮テキストがある画面だけ** 1 画面 = 1 シートを作成し、`template`(ヘッダと空の書式行のみ)を最後に配置 |
| 列 | 下記「列定義」 |

`残` シートは作成不要。`template` シートはデータ記入せず、**最後のタブ**として生成する(クライアントが画面を追加するときの複製元)。

**出力ファイル名**: `{SITE_NAME}_原稿シート.xlsx`。`{SITE_NAME}` はテーマ `inc/config/config.php` の `SITE_NAME` を正とする(日本語のサイト表示名。`PROJECT_NAME` は使わない)。

### 列定義

| 列 | ヘッダ | 記入内容 |
|----|--------|----------|
| A | 対象箇所 | セクション/役割の簡潔な説明 |
| B | demo環境原稿 | **現状の実装文言**をそのまま(`(仮)` やダミー反復も含む) |
| C | 説明・制約 | **通常は空欄**(下記「C 列」) |
| D | 実際の原稿(こちらの列にご入力ください) | クライアント記入用。**空欄のまま** |
| E〜G | 修正原稿1 / 修正原稿2 / 修正原稿3 | クライアント記入用。**空欄のまま** |

画面キャプチャの列は持たない(画像埋め込みはしない)。

### C 列(説明・制約)

文字数の目安やレイアウト上のルールを見て自動記載しない。次のときだけ書く。

| とき | 書く内容 |
|------|----------|
| ソースに `TODO：テキスト差し替え(原稿：…)` がある | `{指示の要約}`(実装時に TODO と一緒に残す。正本: `.cursor/rules/figma/figma-rule.mdc`「アノテーション」カテゴリ「原稿」) |
| 依頼文で C 列/説明・制約の記入を指示された | その指示内容 |

どちらも無ければ空欄のまま。文字数制約の推測(「現状〇文字前後」等)は書かない。

## 仮テキストの判定(正本)

判定・TODO 記法の正本は `.cursor/rules/figma/figma-rule.mdc`「仮テキスト(TODO コメント必須)」。Claude 側には未移行のルールのため、直接 Read する。長文をここに複写しない。

抽出の優先順:

1. **主**: ソース上の `TODO：テキスト差し替え(…)` に紐づく文言(配列定義側の TODO 含む)
2. **補**: TODO 漏れでも同節の判定表に明らかに当てはまる文言(`(仮)` 先頭・末尾、役割説明ダミー、繰り返しダミー、動的未実装の固定仮置き)

含めないもの:

- 本番確定と判断できる文言(TODO なし・仮マーカーなし)
- 画像差し替え TODO(`TODO：画像差し替え` 等)→ 本スキル対象外
- ルール/スキル/ドキュメント内の例文

**1 画面に仮テキストが 0 件なら、その画面のシートは作らない。**

## テキスト列の行高(必須)

A/B/C 列は **折り返し表示(wrapText)** を有効にし、**固定行高のみは禁止**。各データ行の行高は、セル内容から自動計算する。

1. 改行 `\n` がある場合は段落ごとに行数を数える
2. 折り返しは列幅から 1 行あたりの文字数を見積もり、必要行数を算出する
3. 同一行の A/B/C のうち **最大の必要行高** をその行の行高に採用する

目安: 1 行あたり 15pt 前後 + 上下余白。最低行高は 18pt 程度。Excel 手動の自動調整と数 pt ずれることは許容する。

## 画面の単位

| 項目 | 内容 |
|------|------|
| 単位 | `pages.php` 等の **ページ(slug)**。共通ヘッダー/フッターのみの仮文言は、依頼が無ければ「common」等 1 シートにまとめてよい |
| シート名 | 画面が分かる短い名前(Excel 上限 31 文字。slug または日本語画面名) |
| A 列 | ファイルパスだけの羅列にしない(セクション・役割が分かる文言) |

同一文言が配列で複数回使われる場合は、定義側を 1 行にまとめ、A に件数や用途を補足してよい。

```
- [ ] Step 0: 出力パス決定・`write-excel-file` の導入確認(未導入なら依頼者へ `npm install` を依頼。テンプレ xlsx は触らない)
- [ ] Step 1: テーマ/フロントルート特定(`.cursor/skills/project-env-setup/reference.md` の判定に準拠)
- [ ] Step 2: 仮テキスト抽出・画面ごとにグループ化
- [ ] Step 3: 0 件の画面は除外。対象一覧を短く報告
- [ ] Step 4: 各文言の C 要否を判定。`TODO：テキスト差し替え(原稿：…)` または依頼指示があるときだけ記入。どちらも無ければ空欄
- [ ] Step 5: 「Excel 出力仕様」の書式で画面シートを生成 → A/B/C 記入(D 以降は空欄)
- [ ] Step 5-1: `template` シートを最後に生成(`残` は作成しない)

```

ビルド・コンパイルは実行しない(`CLAUDE.md`「ビルド・コンパイル」)。

## Excel 出力仕様

xlsx の読み書きライブラリと共通書式の正本。`image-sheet` / `manuscript-injection` も本節を参照する。

### ライブラリ

- 書き出しは **write-excel-file**、読み取りは **read-excel-file**(いずれも Node.js)。`exceljs` / `openpyxl` は使わない
- フロントエンド `package.json` の **`devDependencies` に常設**(`resources/` がある場合はそこ。`sharp` と同じ場所)
- **都度の一時インストール/完了後の uninstall はしない**。実行は既存の `node_modules` を使う
- 一時スクリプトはスクラッチパッドに置き、`createRequire('<package.json のあるディレクトリ>/package.json')` 経由で `write-excel-file/node` / `read-excel-file/node` を読み込む
- write-excel-file は **新規生成専用**(既存 xlsx を開いて編集・シート複製はできない)。全シートを 1 回の `writeExcelFile([{ sheet, data, columns, ... }, ...])` で書き出す

### 共通書式

テンプレ xlsx の見た目をコードで再現する。テンプレの見た目を変えたときは本表も更新する。

| 対象 | 指定 |
|------|------|
| 全セル | `fontFamily: '游ゴシック'` / `fontSize: 10` / `borderStyle: 'thin'` / `borderColor: '#BFBFBF'` |
| ヘッダ行(1 行目) | `fontWeight: 'bold'` / `textColor: '#FFFFFF'` / `alignVertical: 'center'` / `height: 19.2` |
| ヘッダ背景 | 制作側が記入する列 `#4472C4`、クライアント記入列 `#388600` |
| データ行 | `alignVertical: 'top'` / `wrap: true` |
| シート | `zoomScale: 0.85` |

- 行高は **その行の先頭セルの `height`(pt)** で指定する
- 列幅は `columns: [{ width }]`(文字数単位)
- `template` シートは同じヘッダ + 空の書式行 10 行で生成する

### 原稿シートの列

| 列 | 幅 | ヘッダ背景 |
|----|----|-----------|
| A | 46 | `#4472C4` |
| B | 47.11 | `#4472C4` |
| C | 34.66 | `#4472C4` |
| D〜G | 55.78 | `#388600` |

- データ行は全列とも共通書式のみ(列ごとの背景色・文字色は付けない)
- A/B/C は `wrap: true` 必須。行高は「テキスト列の行高」で自動計算し、固定値のみにしない
- フィルタ/並べ替え前提にしない

## 完了報告

次を必ず含める。

- 出力ファイルパス
- 作成したシート名と、各シートの仮テキスト行数
- C に書いた件数の概要(原稿アノテーション/依頼指示。無ければ 0)
- 仮テキスト 0 件のためスキップした画面(あれば)
