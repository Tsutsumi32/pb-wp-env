# image-sheet

実装中の **仮画像(差し替え対象)** を、クライアント確認用の Excel(画像シート)へ画面単位で書き出す。

**対象外**: 仮テキスト一覧(`manuscript-sheet` スキル)。本番確定画像の転記。

## 入出力

| 項目 | 内容 |
|------|------|
| 書式の参照元 | `_docs/sheets/画像シート_テンプレート.xlsx`(**読み取り専用**。編集・複製はしない。書式は下記「Excel 出力仕様」のとおりコードで再現する) |
| 出力 | `_docs/sheets/{SITE_NAME}_画像シート.xlsx`(既存なら日時サフィックス等で別名。依頼でパス指定があれば従う) |
| シート | **仮画像がある画面だけ** 1 画面 = 1 シートを作成し、`template`(ヘッダと空の書式行のみ)を最後に配置 |
| 列 | 下記「列定義」 |

`残` シートは作成不要。`template` シートはデータ記入せず、**最後のタブ**として生成する(クライアントが画面を追加するときの複製元)。

**出力ファイル名**: `{SITE_NAME}_画像シート.xlsx`。`{SITE_NAME}` はテーマ `inc/config/config.php` の `SITE_NAME` を正とする(日本語のサイト表示名。`PROJECT_NAME` は使わない)。

### 列定義

| 列 | ヘッダ | 記入内容 |
|----|--------|----------|
| A | 対象箇所 | セクション/役割の簡潔な説明(クライアント向け文言。下記「A 列」参照) |
| B | demo環境画像 | **現状の仮画像ファイルのサムネ**(どの画像かを示す) |
| C | 説明・制約 | **通常は空欄**(下記「C 列」) |
| D | pixta ID | 画像内から読めた PIXTA 等の素材 ID。無ければ空欄 |
| E | 備考 | クライアント記入用。**空欄のまま** |
| F | 提供状況(提供済・提供予定・pixta使用等) | クライアント記入用。**空欄のまま** |

画面キャプチャの列は持たない(画面全体のキャプチャは埋め込まない)。

### A 列

**クライアント確認用の資料**であるため、`class` 名・`data-*` 属性・`el_`/`bl_`/`un_` 等の実装側の記述はしない。「MV 背景画像」「サービス一覧カードのサムネイル画像」のように、見た人が画面のどこを指すか分かる一般的な言葉で記述する。

```
NG: .bl_card_thumb / data-module="swiper" のスライド画像
OK: サービス一覧カードのサムネイル画像
```

**「〇〇と同様」等、他行を参照する書き方も禁止。** 仮画像は同一ファイルが複数箇所の仮置きに流用されているだけで、本来はそれぞれ別の画像が入る想定のことがある。行ごとに、その箇所単独で見て場所・役割が分かる文言を書く。

```
NG: 上記と同様のアイコン画像
NG: サービス一覧(2)と同じ
OK: 会社概要ページ MV 背景画像
```

### C 列(説明・制約)

画像の様子(被写体・構図・向き等)を見て自動記載しない。次のときだけ書く。

| とき | 書く内容 |
|------|----------|
| ソースに `TODO：画像差し替え(原稿：…)` がある | `{指示の要約}`(実装時に残す TODO。正本: `.cursor/rules/figma/figma-rule.mdc`「アノテーション」カテゴリ「原稿」→ `.cursor/rules/figma/assets.mdc`「差し替えが必要な画像」) |
| 依頼文で C 列/説明・制約の記入を指示された | その指示内容 |

どちらも無ければ空欄のまま。

## 仮画像の判定(正本)

判定・TODO 記法の正本は `.cursor/rules/figma/assets.mdc`「差し替えが必要な画像(TODO コメント必須)」。情報起点のプレースホルダ配置は `.cursor/rules/project/design-subpage.mdc`「画像(実装時)」。Claude 側には未移行のルールのため直接 Read する。長文をここに複写しない。

抽出の優先順:

1. **主**: `TODO：画像差し替え(…)` に紐づく画像参照
2. **補**: TODO 漏れでも同節の判定に当てはまるもの(sample 表記、PIXTA 等ウォーターマーク、プレースホルダ由来で差し替え予定のもの)

含めないもの:

- 本番確定と判断できる画像(TODO なし・仮マーカーなし)
- テキスト差し替え TODO → `manuscript-sheet` スキル側
- ルール/スキル内の例文・例画像パス
- **アイコン画像**(サービス一覧・SNS・矢印等の UI アイコン類。差し替え対象外のため仮マーカーがあっても抽出しない)

**1 画面に仮画像が 0 件なら、その画面のシートは作らない。**

## サムネ方針

### B 列(現状画像サムネ)

**1 行 = 1 画像。** 画面の切り出しキャプチャは撮らない。テンプレが参照している **既存アセットそのもの**を貼る。

| 優先 | ソース |
|------|--------|
| 1 | `resources/_origin/` の参照ファイル(jpg/png。`DIR_IMAGE_ORIGIN_PATH`) |
| 2 | SVG は `assets/images/svg/` |
| — | **使わない**: 新規キャプチャ、`compression/` / `webp/` / `avif/`(配信用。xlsx 埋め込み前に再 JPEG すると二重圧縮になる) |

挿入手順(崩れ防止):

1. B 列の列幅を固定したまま使う
2. `resources/_origin/`(または SVG)から **xlsx 用の縮小コピー**を作り、列幅に合わせてリサイズ(縦横比維持)
3. リサイズ後の高さに **その行の行高を合わせる**(行高 ＜ サムネ表示高は禁止。画像はアンカーセルの外へはみ出して次の行に重なる)
4. 画像の `width` / `height` は **px**(`dpi: 96` 指定時)、行高は **pt**。`px × 72/96` だと見切れるので、B は **表示高さ(px)+余白を pt として行高に使う**
5. Excel の行高上限は **409pt**。それを超える縦長は、行高を上げるのではなく **サムネを縮小して収める**(引き伸ばし禁止)
6. セル変形で画像を引き伸ばさない(固定サイズ配置)

`resources/_origin/` / `svg/` は削除・上書きしない。縮小コピーは Claude Code のスクラッチパッド(セッション用の一時ディレクトリ)に置き、埋め込み後に削除する。

### 容量最適化(必須)

- B 列は **`resources/_origin/`(SVG は `svg/`)の既存ファイル**を使う(新規キャプチャしない)
- **埋め込み前に縮小コピーを作成して使う**。目安: **列幅に合わせた実寸まで縮小**(原寸の `resources/_origin/` をそのまま埋め込まない)
- JPEG 化するときは **品質 82〜88・chroma 4:4:4**(品質 75 以下は写真が白っぽく/半透明に見えるため禁止)
- 不透明度は変更しない。アルファがある場合は白背景へ flatten してから JPEG 化する
- 元画像(`resources/_origin/` / `svg/`)は編集しない。縮小コピーはスクラッチパッドで一時生成する。
- 出力後は xlsx 容量を確認する。写真が褪せるなら再圧縮せず品質を上げて再出力する
- 縮小コピーは作業完了時に削除する

### テキスト列の行高(必須)

A/C 列(必要なら D 列)は **折り返し表示(wrapText)** を有効にし、**固定行高のみは禁止**。各データ行の行高は、セル内容から自動計算する。

1. 改行 `\n` がある場合は段落ごとに行数を数える
2. 折り返しは列幅から 1 行あたりの文字数を見積もり、必要行数を算出する
3. 同一行のテキスト列(主に A/C)のうち **最大の必要行高** を採用する
4. B 列サムネの表示高さがそれより大きい場合は、**サムネ高さを優先**する(換算・409pt 上限は上記「B 列」)

目安: 1 行あたり 15pt 前後 + 上下余白。最低行高は 18pt 程度。

### D 列(pixta ID)

B に貼る元画像を画像認識で確認し、`pixta.jp - {数字}` やウォーターマーク付近の ID らしき番号があれば D に記載する。読めなければ空欄(推測で埋めない)。

## 画面の単位

| 項目 | 内容 |
|------|------|
| 単位 | `pages.php` 等の **ページ(slug)** |
| シート名 | 画面が分かる短い名前(Excel 上限 31 文字) |
| A 列 | ファイルパスだけの羅列にしない(セクション・役割が分かる文言。実装メモ禁止は「列定義」内「A 列」参照) |
| 行順 | **画面の上から下の出現順**に並べる(DOM 順・抽出順ではない) |

同一画像ファイルが複数箇所で使われる場合は行を分け、A で箇所を区別する。

## Excel 出力仕様

ライブラリ(write-excel-file)・共通書式・`template` シートの生成方法は `manuscript-sheet` スキル「Excel 出力仕様」を正本とする(`.claude/skills/manuscript-sheet/SKILL.md` を Read する)。本節は画像シート固有の差分のみ。

### 画像シートの列

| 列 | 幅 | ヘッダ背景 |
|----|----|-----------|
| A | 35.22 | `#4472C4` |
| B | 34.22 | `#4472C4` |
| C | 32.22 | `#4472C4` |
| D | 25.22 | `#4472C4` |
| E | 39.33 | `#4472C4` |
| F | 37.44 | `#388600` |

- データ行は全列とも共通書式のみ(列ごとの背景色・文字色は付けない)

### 画像の配置

- シートの `images` オプションで配置する: `{ content: Buffer, contentType, width, height, dpi: 96, anchor: { row, column: 2 }, offsetX, offsetY }`
- `width` / `height` は縮小コピーの実寸 px をそのまま渡す(縦横比固定・セル変形に追従しない配置になる)
- `contentType` は `image/jpeg` / `image/png`。SVG は PNG へ変換した縮小コピーを使う
- `offsetX` / `offsetY` でセル内に余白を取る(罫線に重ねない)
- B 列は行高≧サムネ表示高(px)+余白を pt で確保(見切れ禁止。`px × 72/96` は使わない)。上限 409pt 超はサムネ縮小
- A/C は `wrap: true` 必須。行高は内容に応じて自動計算し、B 列サムネ高との大きい方を採用する
- 画像埋め込み前に縮小画像を生成し、最終 xlsx の容量を確認する
- フィルタ/並べ替え前提にしない
