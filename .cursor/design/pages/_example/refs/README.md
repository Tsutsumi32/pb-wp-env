# refs/

この画面の参考資料の実体を置く。

## 自動判定（`wireframe`）

ファイル名に **`wireframe`** が含まれるものが対象（大文字小文字同一視）。`brief.md` への列挙は不要。

| 種別 | 例 | 役割 |
|------|-----|------|
| 画像ワイヤー | `about_wireframe.png` | 全体構成・レイアウト・装飾の有無 |
| JSON | `about_wireframe.json` | 細部・実装方法（フィールドは `subpage-design-implement/wireframe-json.md`） |

## その他

MCP／Figma URL・追加 md／xlsx 等は `brief.md`「その他の参照」に箇条書きでパス／URL と用途を書く。
