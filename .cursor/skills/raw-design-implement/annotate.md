# 色枠 annotate

実装対象だけを色枠で囲う。装飾の細部は囲わない（後で人がまとめて背景等に書き出し）。

可能なら **正本 PNG** と **annotate 画像**を分ける（色抽出・見た目確認が壊れない）。

## 色と役割

| 色 | 役割 | 実装への効き |
|----|------|----------------|
| 赤 | セクション | `section_*` / セクション塊 |
| 橙 | コンテナ | `ly_container` / `$container-sizes`（最大幅・左右） |
| ピンク | グループ | 汎用ラッパー。**入れ子＝DOM 階層** |
| 黄 | コンポーネント | 既存／新規候補の `bl_*` / `el_*` 等。既存に載るなら外側のみでも可 |
| 青 | メディア（書き出し枠） | `img` / `render_img` 等の型。中身は sample |
| 緑 | テキスト | テキストノード（タグ種は実装時決定） |
| 黒 | その他 | 上記以外の実装要素（線は太め推奨） |

灰色は使わない（デザインと被りやすい）。

## メディア拡張子（色を増やさない）

青枠の **枠内または枠横**に小さく `jpg` / `png` / `svg` と書く。

| ラベル | sample |
|--------|--------|
| `jpg`（省略時も jpg） | `sample.jpg` |
| `png` | `sample.png` |
| `svg` | `sample.svg` |

配置は箇所ごと別名コピー＋ `TODO：画像差し替え`（`figma/assets.mdc` / `design-subpage`「画像」と同趣旨）。AI 生成しない。

## 入れ子

```text
赤 セクション
  └ 橙 コンテナ
       └ ピンク グループ
            ├ 緑 見出し
            ├ 青 写真 (jpg)
            └ 黄 ボタン
                 ├ 青 アイコン (svg)
                 └ 緑 ラベル
```

- 外側が親、内側が子
- 黄で既存コンポーネントに載せられる → **外側だけ**でもよい（中は部品契約）
- 新規ボタン等 → 黄（候補）＋テキスト／アイコンを子枠。分類に迷う実装要素は黒

## 囲う / 囲わない

| 囲う | 囲わない |
|------|----------|
| 実装するセクション・コンテナ・グループ・テキスト・メディア・UI | 後で1枚背景にする装飾のかたまり |
| 意味のある子（文言・アイコン） | 影・余白だけ・細かいパス単位 |

`annotate: on` で囲っていない＝ **コーディングしない**（不足ではなく「後手動」）。
